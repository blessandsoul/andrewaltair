# Локальный запуск (чтобы не ходить в прод ради каждого изменения)

Открываешь сайт на своём компе → меняешь код → браузер сам обновляется. Деплой НЕ нужен.

## Главные адреса (открывать в браузере)

- Сайт: **http://localhost:3000**
- Админка воркшопа: **http://localhost:3000/admin/workshop**
- Демо-комната: создаётся кнопкой «Демо» в админке

> **Локально логин НЕ нужен** — заходишь в `/admin/*` сразу, без пароля. Это включено флагом `ADMIN_DEV_BYPASS=1` в `.env.local`. На проде вход остаётся под паролем (флаг туда не попадает + прод в режиме production). Чтобы вернуть пароль локально — убери `ADMIN_DEV_BYPASS=1` из `.env.local` и перезапусти `npm run dev`.

## Как это устроено (2 части)

1. **Dev-сервер** (Next.js) — крутит сайт на localhost:3000. Меняешь любой `.tsx` → страница сама перезагружается через пару секунд. Это и есть «вижу изменения без прода».
2. **Локальная база** (MongoDB в Docker, контейнер `aa-mongo`) — чтобы воркшоп работал (комнаты, ответы). Прод-база снаружи закрыта, поэтому локально своя.

> `.env.local` переключён на локальную базу (`mongodb://localhost:27017`). Бэкап старого — `.env.local.bak_prebmongo`. Файл gitignored, в прод не попадёт. Прод (Coolify) использует свою базу — на него это не влияет.

## Если перезагрузил комп / что-то остановилось — запустить заново

Открой PowerShell или Git Bash в папке проекта и выполни по порядку:

```bash
# 1. поднять базу (если не запущена)
docker start aa-mongo

# 2. поднять сайт
cd /c/Users/User/Desktop/AGENT/andrewaltair.ge_project
npm run dev
```

Дождись строки `Local: http://localhost:3000` — готово, открывай браузер.

## Когда деплой В ПРОД всё-таки нужен

Локалка — только чтобы СМОТРЕТЬ. Чтобы изменения увидели реальные люди (на телефонах, по QR) — `git push` в main, Coolify соберёт прод как обычно.

## Слайды и сценарий воркшопа — это просто файлы

`deck_ka.html` и `run_sheet.md` (в `agents/centaur/content/20260611_thu_adi_final_workshop/`) — НЕ требуют сервера. Открываешь `deck_ka.html` двойным кликом в браузере. Сервер нужен только самому тулу-комнате.

## Контент дека теперь ВНУТРИ тула (одна лента)

Воркшоп идёт по одной линейной ленте прямо в туле: вопрос → слайд теории → вопрос → … Хост жмёт «შემდეგი» на пульте и не прыгает в дек. Старый `deck_ka.html` остаётся как запасной.

**Куда класть фото/клипы для слайдов тула:** в папку `public/workshop/assets/` со строго такими именами:

```
public/workshop/assets/photo_a.jpg   photo_b.jpg   photo_c.jpg   (3 фото для голосования, 9:16)
public/workshop/assets/clip_a.mp4    clip_b.mp4                  (камера движется / static)
public/workshop/assets/boring.mp4                                (15-сек «скучный» клип)
public/workshop/assets/broken.jpg                               («сломанный» кадр, 3 ошибки)
public/workshop/assets/story_1.jpg   story_2.jpg   story_3.jpg  (пазл: процесс / результат / исходник)
```

Пока файла нет — на слайде видна заглушка с именем файла (тул не падает). Что именно рендерить — описано в `prep_checklist.md`.

**Звук ответа** — твой `answer.mp3` уже лежит в `public/workshop/answer.mp3`. На экране-дисплее при заходе будет большая кнопка «🔊 ჩართე ხმა» — нажми один раз (браузер требует клик), дальше при каждом ответе играет этот звук.
